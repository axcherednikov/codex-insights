# Security Policy

## Supported versions

Security fixes are provided for the latest released version of Codex Insights.
Users should update to the newest available release before reporting an issue.

## Reporting a vulnerability

Do not report vulnerabilities through public GitHub issues, discussions, or
pull requests.

Use GitHub's private vulnerability reporting for this repository:

https://github.com/axcherednikov/codex-insights/security/advisories/new

Include the affected version, operating system, impact, reproduction steps, and
any suggested mitigation. Remove credentials and unrelated conversation data
from the report. You should receive an acknowledgement within seven days.

Please allow time to investigate and release a fix before disclosing the issue
publicly. Confirmed reporters will be credited unless they prefer to remain
anonymous.

## Sensitive data

Codex Insights processes local session history that may contain private source
code, prompts, answers, and secrets. Reports and test fixtures must use minimal,
synthetic examples. Never attach raw session files to a vulnerability report.

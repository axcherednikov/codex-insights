
# Codex Insights project memory

Store reusable, evidence-backed project lessons here. Each lesson should state
its trigger, action, scope, durable source, and condition for reconsideration.
Link confirmed lessons from this index when they are added.

Project facts and the module map are in [docs/context.md](../docs/context.md).
Mandatory conventions and privacy invariants are in [AGENTS.md](../AGENTS.md).
Reuse those sources instead of copying their contents into memory.

Task status, hypotheses, full logs, and working handoffs belong under ignored
`.codex/tasks/`, `.codex/sessions/`, and `.codex/checks/`. Never store private
rollout data, prompts, credentials, or tokens here.

No additional durable lessons have been established during initialization.
This directory is repository documentation, not built-in model memory.
